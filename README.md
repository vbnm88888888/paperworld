# 纸上人间 · AI 文字模拟游戏

纯前端 AI 互动小说游戏，双模式：

- **📖 自由自定**：任意世界观自由扮演——自由捏人、编辑 NPC 人设与头像、AI 随机生成 NPC、世界观编辑器、好感度系统、四层记忆体系（RAG 长期记忆，token 消耗与剧情长度无关）。
- **👑 娱乐圈 · 资本帝国**（仿易次元《玩转娱圈》）：你是不出道的幕后资本（总裁/董事长）。周制回合 + 行动点经营旗下艺人：签约、培训、探班拍戏（剧组/剧名/番位）、接综艺、录歌发专辑、买卖压热搜；艺人沿「素人→十八线→三线→二线→一线→超一线」晋升，包养/潜规则/爬床的圈内暗面与对家资本博弈都由 AI 演出。手机内置「资本」面板 + 微博饭圈生态（仅本模式开启）。

## 界面特色

- **九段式剧情格式**：时间/场景/动态地图/在场人员/正文/日程/探索/旁白/心理活动，段段独立渲染——时间 HUD、羊皮纸地图、人员名册+好感进度、日程清单、探索解锁横幅、系统旁白卡、带头像的内心独白卡；AI 每轮回复强制九段完整。
- **立绘式对话**：NPC 说话弹出大头像 + 头像下方名字 + 气泡，整组弹入动画，galgame 舞台感。
- **横屏舞台**：手机横屏自动切双栏——左侧剧情流，右侧情报栏（时间/场景/地图/人员/日程/探索/旁白实时跟进）；竖屏单栏照常玩。
- **深浅双主题**：暗色「鎏金夜宴」/ 浅色「绢纸书斋」，衬线标题 + 纸纹质感；正文字体/字号/颜色可调。
- **仿手机界面**：微信聊天（同步进主线剧情）、朋友圈、微博热搜（娱乐圈模式）、可自定义壁纸。

## 使用

1. 打开网页 → 首次引导中填入 [DeepSeek API Key](https://platform.deepseek.com)（仅保存在你自己的浏览器里）
2. ➕ 新建故事 → 选模式（自由自定 / 娱乐圈）→ 四步向导 → 开始游玩
3. 娱乐圈模式：手机 →「资本」app 点选艺人执行行动（探班/买热搜/夜访…），AI 演出剧情并回报数值；「进入下一周」结算流水与随机事件

## 数据与隐私

- 所有故事、NPC、记忆、API Key 都存在**本地浏览器**（localStorage + IndexedDB），不上传任何服务器
- 长期记忆存 IndexedDB；每 36 条消息自动压缩为「前情提要」
- 建议定期「设置 → 导出全部备份」；换设备用「导入备份」迁移

## 本地运行

无任何依赖：双击 `index.html` 即可（或访问 `app.html` 独立入口）。或在目录下起一个静态服务后访问（局域网内手机也可打开，横屏体验最佳）。

## 部署

整个目录是纯静态站点，可托管到任意静态空间（EdgeOne Pages / GitHub Pages / Netlify 等），无需构建。

## 开发工具（tools/，非运行必需）

- `mock-deepseek.ps1`：本地 Mock DeepSeek API（SSE 流式），用于无 Key 调试
- `static-server.ps1`：极简静态服务器（PowerShell，监听 0.0.0.0:8080）
