# 纸上人间 · AI 文字模拟游戏

纯前端 AI 互动小说游戏：13 种题材（现代都市/校园/娱乐圈/豪门/古代言情/宫斗/武侠/修仙/ABO/科幻/末日/悬疑/西幻），自由捏人、编辑 NPC 人设与头像、AI 随机生成 NPC、世界观编辑器、好感度系统、仿手机界面（微信/朋友圈/微博）、四层记忆体系（RAG 长期记忆，token 消耗与剧情长度无关）。

## 使用

1. 打开网页 → 首次引导中填入 [DeepSeek API Key](https://platform.deepseek.com)（仅保存在你自己的浏览器里）
2. ➕ 新建故事 → 四步向导（题材/世界观/捏人/NPC）→ 开始游玩
3. 现代类题材自动解锁手机界面：微信聊天会同步进主线剧情，朋友圈/微博与剧情联动

## 数据与隐私

- 所有故事、NPC、记忆、API Key 都存在**本地浏览器**（localStorage + IndexedDB），不上传任何服务器
- 长期记忆存 IndexedDB；每 36 条消息自动压缩为「前情提要」
- 建议定期「设置 → 导出全部备份」；换设备用「导入备份」迁移

## 本地运行

无任何依赖：双击 `index.html` 即可。或在目录下起一个静态服务后访问（局域网内手机也可打开）。

## 部署

整个目录是纯静态站点，可托管到任意静态空间（EdgeOne Pages / GitHub Pages / Netlify 等），无需构建。

## 开发工具（tools/，非运行必需）

- `mock-deepseek.ps1`：本地 Mock DeepSeek API（SSE 流式），用于无 Key 调试
- `static-server.ps1`：极简静态服务器（PowerShell，监听 0.0.0.0:8080）
